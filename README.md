# fomo-desk

Static iPhone web app for a personal FOMO trading desk (Plan B: GitHub Pages).

- No secrets in this repository.
- Open the Pages URL with a one-time `#d=` hash (data path) so the app can poll its private JSON under `/d/.../`.
- Push notifications use Discord (webhook stored off-repo). Telegram and web-push are not used on Plan B.

FOMO links never include referral/use codes.
